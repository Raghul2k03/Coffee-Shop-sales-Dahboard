# Coffee-Shop-sales-Dahboard
# ☕ Coffee Shop Sales Dashboard | Excel Project

## 1. Project Overview
The Coffee Shop Sales Dashboard is an interactive Excel-based analytics project designed to analyze sales performance, revenue trends, profit distribution, and customer purchasing patterns across different product categories and cities.  

This dashboard converts raw sales data into meaningful business insights using dynamic charts, KPIs, slicers, and data visualization techniques.

---

## 2. Project Objective
The main objectives of this project are:

1. To analyze coffee shop sales performance  
2. To monitor revenue and profit trends  
3. To identify top-performing product categories  
4. To track monthly and yearly sales performance  
5. To visualize city-wise revenue contribution  
6. To create an interactive business dashboard using Excel

## 7. Key Insights Generated
Important business insights identified from the dashboard include:

- Coffee beverages and desserts generate high revenue  
- Weekend sales transactions are comparatively higher  
- Revenue contribution varies across cities  
- Monthly sales and profit trends help identify peak business periods  
- Specialty drinks and sandwiches show consistent customer demand
